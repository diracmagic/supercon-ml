# Hurricane batch3 source curation

This package records original public source files and reproducible local adapters. It contains no response arrays, workbooks, ZIP data, paper PDFs, ledger records or trained models. Obtain the files yourself under the relative `raw_path` values in `source-registry.json`; then check their SHA256 values. Byte equality does not authenticate a paper's scientific claims, sample identity, calibration or superconductivity.

The three numeric studies provide 69 curves or trace representations and 157,488 table-point records, including eight explicit missing responses. They are not 69 independent samples. Only five curves are broad-temperature longitudinal resistivity: three LSCO films and two FeTeSe films, covering 200/225/250 K, from two papers and two families. None currently has a verified same-specimen numeric **midpoint** Tc target. `hurricane-readiness.json` records zero target links, zero fits and zero LOFO runs. This is a collection/readiness report, not an effect test or a frozen eligibility policy.

## Sources and boundaries

- **LSCO**, [Wu et al., Nature547,432-435(2017)](https://doi.org/10.1038/nature23290): thirteen publisher source workbooks plus the [OSTI author manuscript](https://www.osti.gov/servlets/purl/1412648). The public subset is not the complete thousand-device experiment. The prepared longitudinal and even-in-field transverse responses are distinct; neither transverse response nor pickup voltage is silently relabelled Hall response or calibrated susceptibility. Source rich-text Symbol font means micro-ohm cm. Mobile-hole density p is not nominal Sr x. The 40.8 K screening-onset/resistive-zero claim belongs to ExtendedData2, whose physical identity with the Figure1 p=.16 film is unverified. No separate open-data licence was identified: source arrays and adaptations remain local.
- **FeS/FeSe/FeTe**, [Zhou et al., Nature Materials22,450-458(2023), online2022](https://doi.org/10.1038/s41563-022-01291-5): the [institutional author PDF](https://n04.iphy.ac.cn/allpdf/2022papers/zjd_NM.pdf) and publisher SI were inspected. Figure5 gives resistive-midpoint Tc3.3/7.3/11 K for tetragonal specimens. No author numeric R(T) file was obtained in this search. A paper graph is not fabricated into an original numeric dataset; these claims create no prepared curves or labels. Additional data are stated available on reasonable request, which was not made.
- **FeTeSe Planckian study**, [Romero III et al., Nature Physics22,851-855(2026)](https://doi.org/10.1038/s41567-026-03266-8), [Zenodo18662533 v1](https://zenodo.org/records/18662533): thirteen original workbooks, repository MD5 and SHA256 checked. Dataset CC-BY4.0; article/preprint rights are separate. Full text inspected is [arXiv2505.00623v1](https://arxiv.org/abs/2505.00623), not asserted identical to the final publisher version. Two 100 nm films have reported DC Tc13.2/11.8 K, but the inspected text does not specify a midpoint criterion. Original unit is **milliohm mm**, values retained. Author fit columns are excluded. Twenty exact-zero table rows at integer 0-9 K are retained and flagged; they are not asserted to be individual instrument measurements. Optical fits and repeated DC representations do not add independent samples.
- **Infinite-layer nickelates**, [Yip et al., Nature Communications(2026)](https://doi.org/10.1038/s41467-026-75922-9), [Zenodo20636178 v1](https://zenodo.org/records/20636178): original ZIP verified, dataset CC-BY4.0, article CC-BY-NC-ND4.0. Five author sample labels have explicit midpoint Tc claims. Prepared data are **low-temperature signed-field scans**, not broad normal R(T); superconducting/reentrant regions are not automatically labelled normal. Hc2 outcomes and calculation tables remain outside prospective features. Figure1F (paper S2) and Figure3B pair2 (header S4) show strong repeated-trace evidence with conflicting sample labels. Original labels/bytes are retained; pair2 has unresolved specimen identity and no Tc join. The extra 1.8 K trace drawn in published Figure1B is absent from its source header and is not invented.

Each paper/source is a grouping unit and every composition, field, angle and repeated representation of that study stays together. Three LSCO dopings are one cuprate family. Numeric pressure, field, carrier fraction and strain remain unknown when not explicitly established; growth pressure, nominal dopant content and sample-processing conditions do not become measurement conditions. The adapters do not import `ml.normal_state`, change policy, fit models or read/write a ledger.

## Rebuild locally

Python3.10+ and `openpyxl` are sufficient; no ML, Torch, JAX, MACE or PDF reader is needed for numeric extraction. Use an external local source directory, for example `local-hurricane`, with the hierarchy shown by the registry. Keep the workbooks and ZIP unchanged. `input-metadata/` contains retrieval logs only, used when corresponding original local logs are absent.

```sh
python verify_bundle.py --data-root /path/to/local-hurricane
python extract_lsco.py --data-root /path/to/local-hurricane
python extract_fete_fese.py --data-root /path/to/local-hurricane
python extract_nickelate.py --data-root /path/to/local-hurricane
python build_metadata.py --data-root /path/to/local-hurricane --output-root /path/to/rebuilt-hurricane-metadata
```

Adapters write derived curation JSON only below the specified local source directory; do not point them at a ledger or the repository. The metadata builder writes only the separate output directory. Use `python verify_bundle.py --data-root /path/to/local-hurricane --rebuild --scratch-root /path/to/scratch` for an isolated roundtrip: it copies registered inputs to a temporary directory, runs all three adapters, and compares rebuilt compact JSON without modifying the original data. `--data-root` is optional for the static package check. The full evidence check also requires the five local PDFs in the registry; none is distributed here.

All public files use LF and stay below70 KB. Per-curve numerical arrays and low-temperature row-index arrays are replaced by counts and canonical JSON SHA256 digests. The source registry preserves original-byte SHA256; curation hashes use canonical JSON to avoid platform newline differences. `source-search-disposition.json` records what this bounded search did and did not obtain; an unsuccessful search is not evidence that measurements do not exist.
